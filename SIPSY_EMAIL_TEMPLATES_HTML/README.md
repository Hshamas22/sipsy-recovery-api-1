## 📝 What to Customize

Each template has placeholders you can customize:

### In All Templates:
- `[Name]` → Replace with `{{customer_email}}` or `{{first_name}}`
- `https://sipsy.com` → Your store URL
- Discount codes → Match what you set up in Shopify
- Discount percentages → Adjust as needed

### Product Templates (Tequila/Whiskey/Champagne):
- `[PRODUCT NAME]` → Actual product name
- `[X] years aged` → Actual details
- `[flavor profile]` → Actual tasting notes
- `[quantity] bottles` → Actual stock info
- `[Awards/recognition]` → If applicable

### Gift Guide:
- `[SEASON]` → "Spring", "Summer", etc.
- Price ranges → Update to your products

## ✅ Launch Checklist

Before sending campaigns:

- [ ] Create segments in Shopify Customers > Segments
  - Tequila: "has purchased" contains "tequila"
  - Whiskey: "has purchased" contains "whiskey"
  - Gift: "has purchased" contains "gift"
  - Champagne: "has purchased" contains "champagne"
  - VIP: "number of orders" = "2 or more"
  - Never Purchased: "number of orders" = "0"

- [ ] Verify discount codes in Shopify
  - WELCOME20 (20% off, first purchase only)
  - TEQUILA15 (15% off)
  - WHISKEY15 (15% off)
  - GIFT20 (20% off)
  - CHAMPAGNE15 (15% off)
  - VIP25 (25% off, 24-hour expiration)

- [ ] Test email on mobile phone
  - Open in email app
  - Check CTA buttons click correctly
  - Verify code is readable
  - Check images load (if added)

- [ ] Personalize [Name] placeholders
  - Use {{first_name}} or {{customer_first_name}}
  - Check what your platform uses

- [ ] Pick send time
  - 9 AM or 7 PM typically best
  - Wednesday-Thursday best days

- [ ] Send to one segment first (test)
  - Send to smallest segment first
  - Monitor for 24 hours
  - Check open rate, clicks
  - Then roll out to other segments
