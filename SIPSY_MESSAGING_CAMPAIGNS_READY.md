## Implementation Steps

1. ✅ Create segments in Shopify Customers → Segments
2. ✅ Segments auto-sync to messaging app
3. ✅ Open campaign above for your segment
4. ✅ Copy message text → paste in messaging app
5. ✅ Add CTA button with link
6. ✅ Add discount code
7. ✅ Schedule send or send immediately
8. ✅ Monitor metrics (open rate, click rate, conversion)
